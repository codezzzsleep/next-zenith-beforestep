## 各类画面对应的事实

Lux3D 接收普通 RGB 图片，返回物体级静态几何。BeforeStep 用 RGB-D、位姿和地形配准到局部世界；MuJoCo 计算运动和碰撞。当前游戏复用原 R1 输入与真实返回，没有实时提交游戏帧。

当前评审局是两候选世界，原 R1 是十二组合世界。当前录制展示 M20 外观，原 R1 保留 Go2W 机身；两者沿用冻结动力学，但不能称为新实机成果。母片、停车与布局补拍分别标识各自的捕获代码版本。

原 R1 112.84 秒是执行的仿真时间，当前 4:59.667 是母片视频时长，最终 112 秒是剪辑目标，三者分别使用。灰线在已测候选中也可能通过，不固定剪成必撞结果。

素材已经上传，原视频已全解码、成员 SHA 和 ZIP CRC 已核对，GitHub 附件 digest 已核对。匿名整文件 GET 的实际范围见原片目录；不将部分检查写成全部完成。
