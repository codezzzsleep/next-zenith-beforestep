# 随机场景中的学习导航：v1 实验协议

2026-11-12 按用户的新要求增加实际训练的导航模型。R1/R2/R3 及 C1–C8
继续按已发布结果保留。本实验使用独立代码、权重、种子和报告。

模型读取已观测占据、已知区域、已生成几何先验及先验可用区域，预测机器人
可通行概率，再用可微神经价值迭代输出八个移动方向的分数。卷积参数、运动代价、
风险代价、折扣和方向偏置实际优化。八邻域传播结构是固定归纳偏置；运行时不调用
训练示教的 Dijkstra。共同的已观测障碍防撞门卫、感知更新和电机伺服仍有规则。
不能将该系统写成所有层次都由网络自主学得。

## 数据与信息边界

- 使用既有 27 组真实 Lux3D/扫描几何叠合，抽取俯视凸包，以共同的随机尺度、
  方位和位置迁移到新环境。这是**缓存形状先验的迁移实验**，不是新照片重新调用
  Lux3D。保留原任务号和 SHA，不把随机生成环境写成新的真实 Lux 生成成功。
- 真值只供仿真碰撞、模拟传感器和离线监督标签使用。推理输入没有真值通道。
  只有模拟传感器看见某块岩石后才提供其缓存先验。先验可能比真值短或长。
- 第一阶段是 0.30 米格子的二维运动和视线/阴影模拟，不等同冻结的 5cm RGB-D
  生产系统。另用同形状、同起终点的 MuJoCo 轮腿机器人验证物理执行；不能把
  二维格子的成功计作 MuJoCo 成功。
- 验证场景首先发现物理边界墙与矩形车身初始重叠，规则/网络均在初始化后立即
  接触。首次两份失败保留；物理墙向地图外偏置一格，地图仍使用原保守边界，
  岩石、起终点和模型不变。此适配在任何物理留出测试之前固定。
- 随机生成器改变岩石数、位置、方位、尺度、起终点、太阳条件。不可达场景也保留；
  按全部任务和可达任务分别计数，不挑成功布局。

## 预先固定的比较

参数权威：[navigation_v1.json](../config/training/navigation_v1.json)。训练1024种子，
验证64种子；验证集用于权重选择。固定权重后一次评估测试128种子与分布外128种子。
分布外增大岩石数量与尺度；这些几何源仍属于既有库，所以只能主张布局/密度/尺度
泛化，不能声称未见岩石类别泛化。物理测试另有8个新种子。所有种子区间互不重叠。

比较保守规则、乐观规则、缓存先验规则、训练网络、未训练网络、训练网络去掉
缓存先验。使用同一任务、传感器、观测预算和已知障碍门卫。报告到达、碰撞、
停止/超时、路径长度、观察次数、模型/规划耗时和逐场失败。先报告首次完整测试；
若据测试修改实现，必须保留结果并另起版本及新留出种子。

LLM 对照参考 [Agentic Observer](https://github.com/codezzzsleep/gosim26-agentic-observer)
的数值证据加模型判断方式：客户端接收结构化候选动作与可见性/风险摘要，返回
候选编号或请求观察，程序校验结构和候选身份。没有真实服务调用和执行记录时，
仅记为接口实现，不写成大语言模型验证通过。模型服务配置在私有环境文件中。

本实验不预设网络会超过规则。最终结果才能决定作品是否已经具备所要求的泛化。

可达场景共63场。此结果不支持网络超过规则。保留所选权重
`de1dcec57a7debae25e611c5e46a45becb1634b1042ee22bed751917c70fa413`，不据验证
改导航参数。物理边界修复后同一验证种子2100063两方法均无碰撞到达。
留出运行前固定所有导航源文件摘要；物理规划耗时另按真实调用计时。

与新请求共同受32总上限约束。此补充只验证服务与混合决策接口，不构成大样本
LLM泛化或优于规则的证据。认证拒绝后停止本次后续请求。
