# BeforeStep 月面探索任务

打开 [月面探索](https://codezzzsleep.github.io/next-zenith-beforestep/play.html)。任务是绕过高石、跨过可见门槛，抵达青绿色信标。先学操作，在第一视角体验有限观测，再启用 Lux3D 空间想象，从局部三维假设预测通行，最后执行探索。M20 外观、v3 报告的纸白、深蓝、金色和宋体标题延续到游戏。

本轮增加四站任务目标、探索检查点、全程挑战、六枚勘察印记和本机个人纪录。可以换一组已有真实高石模型开新局，让新的选择重新参与规划与物理试路。主报告保持 V3，主宣传入口使用作者已发布的 B站视频；规则与复现见[可玩性增强](playability.md)。

## 如何游玩

开场先显示目标与操作说明，真实机器人保持暂停；点开始或按 Enter 才出发。WASD / 方向键驾驶，空格刹车，E 观察；逐步提示前进、松开前进键刹车，再继续靠近高石。前行约 55 cm 到达观察点后由真实轮子电机制动。此时第一视角只显示二维轮廓感知示意，外部相机暂不可切换；按 Q 主动启用前额叶空间想象。玩家转看所选高石 A 的完整候选，查看它在通道中的三维占地，再点“预测这条路线”。当前选择和停稳起点下的完整预测通过后，才释放首次手控或按认证路线出发。执行时 V 可切第一、第三、俯视，画中画同时显示相机和机器人；手机用摇杆与对应按钮。

石体始终使用现有碰撞世界包中的完整原始表面，保留原 UV 和连续法线。初始的二维轮廓仅临时替换显示材质、移除纹理与光照线索，不裁掉三角面，也不改 RGB-D 或物理信息。开始实际探索后恢复原扫描贴图、原月壤材质与低角度太阳阴影。机器人实际观察仍由 MuJoCo 射线计算；脑内地图的斜纹表示原始记录观测的盲区，Lux3D 候选在标注的假设世界中参与规划和物理预演。核对见[完整石体显示修正](solid-rocks-20261118.md)及[空间想象体验](spatial-imagination-game-20261118.md)。

Lux3D 气泡展示官方 Aholo Viewer 载入的原始返回 GLB，可以拖动转看另一面、点击“看背面预测”或换候选。同一窗口直接显示配准后的三维局部空间，也可切俯视比较占地。仅载入或自动旋转不会跳过必经展示；看过的候选从选集中移除后，需要转看当前所选模型。每份模型紧邻它真正提交的原照片、任务身份和来源。游戏复用原 R1 的 11 份真实返回与冻结核对数据，其中 8 份符合观测；没有提交当前相机截图或新生成请求。“前额叶”比喻空间想象模块的角色。

默认选择 A 的一份、B 的两份候选，组成两个碰撞世界。玩家可以加入更多假设，也可以比较“留出背面空间”和“只按可见面试路”。停稳后开始脑内试路，看到小机器人在完整候选环境中真实驱动。所选 GLB 的原配准网格构成 MuJoCo 碰撞几何；模型选择改变规划占据与 A × B 组合。取消或改变选择立即失效旧结果。

恢复手动或辅助驾驶后，同一个官方原 GLB 视窗缩成机器人旁的小思想气泡，模型继续旋转。第一视角中气泡放在角落；第三视角中用小圆点连到机器人。经过第二块高石时，提醒并载入所选 B 的假设，不再次锁住驾驶。展开气泡仍可比较候选、改走法和取消试路。金色虚线是未认证参考，只有实际完成所有所选世界的预演才显示通过。

经过预演的辅助路线必须从当前停稳位置实际完成所有所选世界的预演；选择修订和起点快照绑定。玩家移动后，旧结果保留为该快照的试路记录，不能直接用它验证新起点。执行途中方向键或摇杆随时接管；沿原路线附近可以恢复同一条已验证路线，离开路线则要求重新试路。系统不重新规划一条路线却沿用旧通过状态。

门槛可以先尝试轮行，也可以停稳、对正后直接尝试迈腿，或先进行当前可见门槛几何的真实跨越预演。门槛高约 12 cm、宽约 10 cm，四轮半径约 8.6 cm。1–4 选右前、左前、右后、左后，J 抬、K 迈、L 落；动作旁的状态和选中轮的金色标记帮助观察。玩家分别触发四条腿的 12 个主要跨越动作，控制器辅助重心、平衡及必要的支撑准备，动作不是整段自动播放。自由腿操作也可尝试，先落稳再恢复轮行。

进入 35 cm 目标圈且四轮越过门槛后，轮子电机制动停稳并判定抵达。探索练习可按 R 回到最近的实际停稳检查点，或从起点再来；全程挑战从起点一次完成。恢复检查点会清空旧预演认证，结果卡列出继续次数，成绩与研究实验分别记录。音效默认关闭，台词与操作提示始终可见。

## 实现与事实边界

`mission-worker.js` 持有持续运行的真实世界，脑内预演使用另外的临时 `MissionWorld`。第一、第三、俯视和画中画消费同一真实状态快照；脑内世界单独标注。预演取消采用修订令牌，不替换或重置真实机器人。除重置、独立预演初始化外，机器人位姿来自原 16 个执行器的力矩与 MuJoCo 运动计算。

`mission-showcase.js` 管理观察点、转看模型和驾驶释放，展示状态不等同预演认证。worker 在锁定期间拒绝驾驶与提前腿操作，停稳来自电机与物理求解，不修改机器人位置。`mission-session.js` 检查候选修订、通过结果、起点位置、朝向和停稳；恢复辅助只续走原路径。`mission-story.js` 负责开场、分步操作教学、感知与想象的对比及首次出发前的有效预测要求。`mission-scene.js` 管理两类世界显示与相机，`mission.js` 连接实际输入、候选、预演与执行。原规划净空、候选准入、轮腿控制与原研究输入/结果保持原件。

本页是新的交互体验，门槛与游玩结果独立于原 R1 / R2 / R3。模型符合可见观测及所选世界预演通过仍不保证未知背面正确；实际行动由原月面碰撞场景计算。旧驾驶练习保留于 `play-practice.html`。

## 验证与复现

运行原完整任务物理检查以及新的体验检查：

```sh
node tools/beforestep_mission/check_mission.mjs /tmp/mission-physics.json
node tools/beforestep_mission/check_experience.mjs /tmp/mission-experience.json
node tools/beforestep_mission/check_showcase.mjs /tmp/showcase.json
node tools/beforestep_mission/check_worker_mission.mjs /tmp/showcase-complete.json --showcase
```

第一项覆盖 12 个真实模型世界、真实场景绕行、相机门槛测量、跨越和终点，以及纯轮阻挡和仅可见面的碰撞对照。第二项验证修订/位置/朝向/速度失效、候选数量及走法影响、实时可见表面、原碰撞角色映射和脑内运行不修改真实位姿。浏览器验收和新版运行证据另见 [体验验证](game-experience-verification.md)。

资源来源见 [资产清单](../site/media/mission/manifest.json)。资产构建仍使用原 `tools/beforestep_mission/build_assets.py`，不重新请求 Lux3D。部署保留 [Pages 素材适配](pages-delivery.md)，避免原模型和研究下载链接丢失。
