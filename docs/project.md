# BeforeStep 项目目标与开发原则

BeforeStep 是面向轮腿机器人导航实验的盲区推演系统。它处理的问题是：遮挡和阴影让机器人只能观察到岩石的一部分，可见面之外的几何会影响路线是否可执行。系统用实际观测约束 Aholo Lux3D 生成的多个候选，对候选分别进行物理预演，再决定行动或补充观察。

相关研究、项目贡献与已有同图生成样本的核查见 [文献与创新点依据](related-work.md)。

## 使用对象与任务

使用对象是研究机器人感知、导航与空间生成的开发者。开发者配置场景、起终点和策略，检查系统如何从观测得到候选几何、如何拒绝不符合观测的候选、路线在候选环境中能否完成，以及独立环境中的实际执行结果。

月球南极关口提供一个具体任务：在岩壁、月溪与被遮挡岩石之间完成通行。场景必须可达，并让不完整观测带来的决策问题能够被解释；困难反例用于检验边界，正常任务用于检验完整能力。

## 核心工作流程

1. 获取机器人实际 RGB-D 观测，保留可见、已知自由和未知区域的区别。
2. 使用 Lux3D 生成多个可能的岩石几何，与可见点云配准；不符合冻结观测约束的候选被拒绝并记录原因。
3. 用采纳候选构建占据几何，对规划路线逐份进行物理预演。完整预演通过才支持执行；证据不足时补充观察，仍不足时停止。
4. 在独立物理环境执行路线，记录碰撞、是否完成、观察次数和终态误差，使预测可以与实际结果核对。

每次实验保存输入、真实生成资产、准入理由、预演与执行记录。关键版本保留可比较的源码、配置、资产和结果，让工程改进有据可查。

## 当前能力与验证范围

当前实现通过命令行运行参数化 MuJoCo 场景，支持实时仿真观测及明确标注的记录观测复现。网页用于切换策略、检查真实生成资产、回放已完成实验；它不是实时生成或控制入口。

v0.3部署实际训练的v4神经网络，直接输出轮速、差速与腿部姿态残差。训练、固定权重和独立评估见[训练记录](training.md)。主任务(5.7,-0.5)的实时Lux链两次完成三候选完整预演与独立到达，加入生成占据改变了路线；原终点(8.5,0)也两次到达。

去掉生成几何的同模型对照也到达；保守方法未满足观察点姿态，属于控制能力限制。当前验证了候选参与决策、训练动作执行与完整任务闭环，尚未验证普遍安全收益、端到端速度优势、通用主动观察或实机能力。旧规则基线和训练失败均保留。

可选的训练朝向网络 v2 与分步交接现已在同一关口完成四眼主动观察和到达，并通过同首次观测的对照与采集瞬间姿态检查。冻结 v0.3 默认控制与历史失败保持可复现；新能力显式通过 `--pose-model` 开启，方法、独立结果及边界见[主动观察控制](observation-control.md)。

## 开发与验收原则

实现以观测、生成、几何、导航、仿真和实验记录的职责划分，保持源码入口、资源恢复与复现方法可维护。核心路径真实运行，页面、报告和视频取材于这些运行记录。

后续实验优先回答生成候选对行动判断的实际作用：在明确且可达的任务中，用一致对照检查哪些选择受生成几何影响、何时需要补充观察，以及预演能否解释执行结果。收益成立的条件和失败边界都应记录，不能用一次到达代替这些验证。

验收同时检查有效任务完成、生成资产确实参与决策、候选预演完整、对照一致、材料结论与运行记录一致，以及新环境中的资源恢复与复现。报告和 Demo 是工程成果的说明入口。
