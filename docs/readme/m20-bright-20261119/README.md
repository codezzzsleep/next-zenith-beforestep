# M20 较亮配图

作者指出旧 README 机器人过黑，并指定 V5 Beta 封面中自己截取的较亮时刻作为参照。本目录的 `cover-source.jpeg` 直接提取自该 PDF 的封面图像流，未修改原像素；新探索图、动图前十二帧与模型/行动拼版使用同一张真实截图。

展示裁图为原 2559×1439 画面的 `(620,225,2156,1089)`，保持 16:9，完整保留 M20 四轮、轮腿和随行空间想象面板，去除原上下操作栏。模型照片、实际上传给 Lux3D 的输入、原 GIF 的模型旋转帧与六版本资产不变。

十二世界图另存提升暗部的显示副本（gamma 0.68），便于看清小图里的机器人；原图片、真实网格、预演结果和物理记录仍保留。该显示调整不作为新的研究结果。

[sources.json](sources.json)逐项记录原 PDF、原封面截图、裁图、旧资产、新文件和 SHA。重建脚本为 [build_v5beta_bright.py](../build_v5beta_bright.py)，接收仓库、原 PDF 与 Noto Sans CJK SC Bold 字体目录，不调用生成或训练服务。
