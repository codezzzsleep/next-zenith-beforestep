# v3 报告的视觉基准与网页映射

设计参考是用户提供的十页《先见一步_项目报告书_v3.pdf》，与站点 [report.pdf](../site/media/report.pdf) 的 SHA-256 相同：67c15f4af8c02c79c4254e55774207acf51796784583e58543c5d482c0199cc6。

报告用纸面的阅读秩序组织问题、方法与结论，用深蓝底板承载真实影像和技术材料。金色帮助读者找到章节、步骤与重点，结果另外使用红色和青绿色。网页沿用这些职责，使读者从报告进入模型工作台和驾驶界面时，仍能认出同一个作品。

## 从报告中读到的规则

| 报告中的实际设计 | 网页中的对应职责 |
| --- | --- |
| 封面为 #0b1320，技术底板为 #142036，配白色文字和淡蓝灰注释 | 首页首屏、模型视窗、仿真画面与实录边框采用深蓝；让真实影像成为主体 |
| 正文页为白色，辅助卡片为 #f5f2ea，边界为 #e3dfd3 | 说明、操作面板、候选信息与阅读器采用白色和暖灰纸面，减少绿色铺底与装饰阴影 |
| #f0a93b 用在章节序号、细线、小方块、流程箭头；浅底上的重点文字用 #b86a0c | 导航当前项、步骤序号、当前选择与下一动作采用金色，保持清晰的注意力顺序 |
| #1f9d8a 用在成功数字，#d9483b 用在失败数字（第4–8页） | 通过、抵达和拒绝保留各自的结果颜色；选中了某个候选或动作，不等于验证成功 |
| 标题为 Noto Serif CJK SC Bold，封面50pt、章节22pt；正文为 Noto Sans CJK SC，常用10.6pt | 中文标题使用同族宋体，正文与操作标签使用同族黑体；指标使用宋体数字，技术键名使用等宽字体 |
| A4正文左右各约15mm，常见双栏间隙4mm；所有章节共用对齐线 | 页面标题、内容与页脚共用宽度和边距；手机重排栏目，但保留字体和层级 |
| 第3页用四个编号说明完整流程，最后一项以深蓝强调；第8页用细金线连接真实迭代 | 游戏进度用小圆编号和细边界；当前动作的强调独立于已完成状态 |
| 第6页把两张同场景影像和各自结果并列，再解释结论；第9页集中呈现模型和输入 | 对照影像保持同尺寸，说明紧贴相应影像；模型和仿真区保持大而完整 |

宋体承担标题的份量，黑体承担连续阅读和操作的清晰度。白色页面的留白、暖灰辅助卡片、深蓝材料区形成节奏；图、说明和结果之间保持明确关系。界面中的按钮和边框遵循这些层级，而不是给所有区域同样的强调。

## 当前页面的应用

- 首页保留照片到真实3D的核心入口，以深蓝首屏、宋体标题、金色重点组织内容，下面回到白色阅读区。
- 模型陈列室采用深蓝模型底板、白色信息区和暖灰候选分组。当前选择用金色，拒绝状态用红色。
- 月面探索让深蓝实时画面占据主体；纸白漫画气泡承载 Lux3D 原模型与脑内试路，宋体标题和金色操作继续沿用报告层级。说明与来源可以展开，下一动作使用金色，通过结果另外使用青绿色。
- 项目报告阅读器的导航、封面和页框沿用纸面规则，PDF原件保持原字节。
- 实验回放、沙盒与保留的练习入口采用相同字体、导航、纸面、视窗和状态颜色。

网页的月面与生成模型仍来自原资产；候选身份、准入阈值、物理几何、规划和轮腿控制保留原实现。报告的字体与公共色彩规则集中在 [report-look.css](../site/report-look.css)，游戏画面和纸白漫画气泡在 [mission.css](../site/mission.css)。持续驾驶、相机、脑内试路与认证边界见 [月面探索实现](mission.md)，新增游玩结果与原研究分别记录。

## 字体来源与复现

使用官方 Noto CJK 的简体中文宋体Bold，以及黑体Regular/Bold，并随站点提供 WOFF2 字体，使不同系统也能呈现相同字形。来源、原字体SHA与网页字体SHA在 [sources.json](../site/fonts/sources.json)，许可在 [OFL.txt](../site/fonts/OFL.txt)。

字体保留当前界面使用的汉字、数字和常用符号；源代码中增加新的汉字标题时，安装fonttools和brotli，运行 tools/report_design/build_fonts.py 更新字体。生成器也支持 --source-dir 复用已下载的三份OTF和许可，字形选择与文件时间戳保持可复现。
