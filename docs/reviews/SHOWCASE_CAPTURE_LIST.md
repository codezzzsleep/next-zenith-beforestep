## 没有素材，不能画个示意图代替的部分

1. **实机轮腿跨越。** 目前没有本项目实机录像。要补拍须在原型机上记录同石轮行、逐轮抬起/落地、失败及完整离开；保留连续广角、侧近景和现场原文件。仿真录像不标成实机。
2. **真实取土/采样。** 当前任务记录验证的是到达，没有采样器实际操作记录。若作品要展示取土，需补完整接近、采样器接触、取样、回收过程，以及真实控制和传感器记录；现阶段不显示虚构的采样成功。
3. **本轮 API 从提交到返回的原始屏幕录像。** 原图片、任务号、返回模型和日志都存在，但没有当时连续的屏幕录像。现阶段展示实际输入与实际返回资产，不能把模型逐份显现称为实时生成。如果将来要拍新调用，先明确另一次演示的预算和身份，不伪装成旧任务。
4. **自由摆石产生的新布局。** 已有原场景可以选择和播放；用户任意新摆的布局没有对应的真实运行录像。要补需保存新布局、在真正物理引擎里运行、保留关节与接触记录、拍摄全程和近景，再将录像与原结果绑定发布。二维布局编辑器保留为分析工具，不把一个图标沿线移动称为真实仿真结果。
