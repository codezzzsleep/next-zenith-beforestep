## 2. P1 首屏与"两种影子"交互（命中 有趣 25% + 创新 20%）

目标：一个没读过报告的人在十秒内说出"太阳的影子看也没用，视线的影子再看一眼就行"。

1. **hero 换成真实画面**：用 `stress_v8` 第一眼的真实 RGB（`evidence/reviews/beforestep_r1/lux/original_b/looks/look1/`，先核实实际路径），叠加标注 A、B 与两类未知区域。禁止用合成图、示意图或生成的假图代替真实观测。
2. **"一块岩石，留下两种未知"改成可拖动的对照**：
   - 一个"再看一眼"的滑块/按钮：拖动后，视线遮挡区域随真实第二眼观测变化，太阳黑影区域不变（因为真实观测也照不亮它）。
   - 图像只用真实首眼/第二眼数据；没有真实第二眼的场景要明确标注"示意"，不得假装有数据。
3. **三车决策提到第二屏**：把现有"先做选择，再揭晓"前置，保持真实的四台车结果（保守/see-dark/乐观/真实 Lux），并给出各自轨迹缩略图。
4. **真实候选可转动**：在候选一节嵌入一个本地 three.js 查看器，加载本仓库内真实准入 GLB（`assets/` 与 evidence 内已公开的对象），能旋转查看；标注任务 ID 与自检结果。只用真实资产，不新生成。
5. **移动端**：390px 宽下首屏不出现横向滚动，按钮可点。

验收：桌面 1440 与手机 390 截图各一张存 `evidence/`，控制台无报错，首屏可交互在 2 秒内响应。
