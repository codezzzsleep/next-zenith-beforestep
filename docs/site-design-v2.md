# 页面体验：从一面照片，推演下一步

首页把实际输入照片和同任务原 GLB 放进首屏，观众直接旋转模型查看另一面。独立驾驶体验紧接其后，三个任务分别练习轮行、逐腿跨越和高石模型绕行。观测核对、组合世界预演与行动结果按阅读顺序展开。

模型陈列室默认选择任务 5958685，并将输入照片、三维查看、当时的检查和完整来源放在同一工作台。继续挑选区保留全部已有 306 份模型，支持检查结论、场景和任务号筛选；通过、被拒、反事实与历史记录继续保留原身份。

正式 v3 报告增加目录、前后页和手机跳页，提供每页直达原 PDF 的放大入口。十页图片和原 PDF 保持原字节。场景回放在切换策略时直接显示原记录结果，自动轮换由观众选择；录像和研究结果没有改动。

首页 Demo 使用已经完成的 185 秒原片。六个章节的跳转时间来自冻结的 `evidence/production-v6/film/timeline.json`，封面复制原成片封面，来源和 SHA 见 `site/media/site-design-v2/sources.json`。没有重新生成、编码或替换任何研究视频。

主要页面共用导航和阅读底色。已有轮腿控制器、物理引擎、机器人资产和原输入/模型不变，本次改进页面布局与交互组织。
