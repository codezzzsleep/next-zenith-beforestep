# 作品入口与动手体验

首页先给出“照片 → 完整三维模型 → 判断与行动”的作品核心和可直接操作的机器人入口。三项体验各有目的：平地轮行、门槛逐腿、高石看模型后绕行。选腿和动作按钮、当前腿标记、接地载荷及分步提示使第一次操作可以在画面旁完成。

照片与同任务原 GLB 的旋转查看、原 Demo、模型核对与预演结果、场景原运行、正式 v3 PDF 继续可以查阅。模型、运行、报告与驾驶舱共用导航，阅读页使用统一浅色底；驾驶画面使用深色背景增强动作辨识。

首页轮腿画面取自新版驾驶舱的实际浏览器物理状态，仅对截图中央区域裁剪缩放；来源见 `site/media/site-redesign/sources.json`。机器人、原照片、生成 GLB、历史版本和科学实验结果保留原身份。新游戏使用已有模型，不创建 Lux3D 请求或训练任务。
