# 完整石体显示修正

之前的主驾驶场景把未观察区域从网格上删除，石头因此变成了有开放边的表面残片。
上一轮修正了局部三角面误裁，但仍保留这个显示方式；重新计算非索引面法线又使
近景呈现明显棱面。用户要求恢复完整实体观感后，本次恢复原世界包中的完整石体。

## 恢复的几何

现有 `worlds.tar.gz` 已包含两块高石的完整表面。只在构建显示缓冲时焊接重复的
UV 顶点、去除重复三角面，再计算连续顶点法线，保留原来的凹凸和轮廓。
没有重新生成石头，也没有用新的凸包替代原物理几何。原扫描文件的开放底面说明
与当前世界包中的已处理网格分开核对，不能据原素材的元数据认定运行包也未闭合。

| 石体 | 存储顶点 / 面 | 完整显示顶点 / 面 | 开放边 | 非流形边 |
| --- | ---: | ---: | ---: | ---: |
| A | 7,914 / 29,688 | 7,424 / 14,844 | 0 | 0 |
| B | 4,067 / 15,272 | 3,820 / 7,636 | 0 | 0 |

两块石体的表面方向一致、Euler 特征均为 2、包围体积为正，使用的顶点法线均为
单位向量。原始输入缓冲和 MuJoCo 物理状态在构建前后完全相同。

主场景撤掉观测裁剪，以完整不透明表面显示石体。恢复原扫描 UV 与旧版去饱和
贴图，覆盖 34 个扫描岩石网格；主场景与预演中的扫描背景都使用原纹理。旧月壤
缓存按 `regolith_texture()` 的原算法和固定种子重建，贴图尺度仍为 0.9 米。
太阳恢复为原场景的 10° 高度、35° 方位，降低补光，以环境与 M20 的实际网格
投射阴影。地面参考路线参与深度遮挡，经过石头或机器人背后时自然被遮住。
默认第三相机与第一视角的外观画中画跟随 M20 的位置和朝向，第一视角用实体
自然遮挡背面。

## 观察与行动

机器人实际观察仍由原 MuJoCo 射线产生，外部相机画面不进入规划。未知区域继续
在脑内地图标示，所选 Lux3D 候选仍构成真实的候选碰撞世界。主场景、机器人相机
和画中画消费同一物理快照；候选核对、预演、执行与游玩结果的规则保持。

原始扫描、Lux3D GLB、配准网格、世界包、XML、碰撞、控制、CDN 上传包和 V3 报告
均保持字节。无需重新上传原 CDN 压缩包。显示补充约 1.56 MB，包括七张网页
JPEG 和原 UV；由网页直接并行读取。原 PNG 的 SHA、尺寸、扫描来源与网页派生
SHA 见[贴图清单](../site/media/mission/appearance/manifest.json)。JPEG 为原贴图
的缩放压缩版本，不宣称与原 PNG 字节相同；月壤继续是项目原有程序材质。

## 验证

网格核对脚本直接读取原世界包与实际 MuJoCo 模型数组，可运行：

```sh
node tools/beforestep_mission/check_rock_surfaces.mjs /tmp/rock-surfaces.json
```

另核对所有 34 个扫描 mesh 的原 OBJ 与实际 MuJoCo 顶点、面片顺序，UV 对齐
一致，最大坐标浮点误差约 0.232 微米。两块主石体保留 UV 后的几何仍与完整
闭合表面相同。原两世界预演、认证路线出发和键盘接管通过，零页面错误。

网页验证与前后图在[本次证据目录](../evidence/solid-rocks-20261118/)。前后图来自
两个独立的真实操作运行；每个运行内的三视角分别在同一暂停物理状态下核对。
本次验证属于显示和交互回归，不重新执行冻结研究或生成新模型。
