# 从空间想象到探索

> 本文保留2026-11-18 空间想象引导的前一阶段记录。当前主报告是 [V5](../reports/README.md)，当前初判后自主手控/想象/补看/停车规则与完整原材质显示见[月面任务](mission.md)，最新原片与验收见[评审试玩](judges-demo.md)。历史测试身份与结果保持原记录。

BeforeStep 给轮腿机器人增加空间想象能力：从有限观测预测局部未知几何，形成可检验的空间世界，再预测路线与行动后果，支持实际探索。我们把这项能力比喻成机器人的前额叶。

Lux3D 对未见的静态几何提出候选。BeforeStep 把候选与观测核对、配准到通道，MuJoCo 再用这些候选几何计算机器人行动的后果。生成模型实际构成碰撞世界，并影响路线选择。

## 玩家经历什么

1. 开场说明目标：绕过高石、跨过可见门槛，抵达青绿色信标。真实机器人先暂停，点开始或按 Enter 出发。
2. 实际学习 W / 方向键前进、空格刹车、E 观察。第一视角以二维轮廓示意有限观测，背面占地仍未知。
3. 到高石观察点由轮子电机制动。按 Q 主动启用前额叶空间想象，看到原照片、真实 Lux3D 候选以及候选配准后的三维局部世界。
4. 转看背面预测，对照亮色可见占地、琥珀色假设占地及两条参考走法，再点“预测这条路线”。默认 A 一份 × B 两份，共两个实际候选世界。
5. 这些世界完整通过、且当前位置和姿态仍有效，才释放首次驾驶。沿预测路线探索或自行接管；执行恢复原岩石贴图、月壤和斜阳，V 可切执行视角，空间假设继续随行。
6. 高石之后的门槛已经可见，进入轮腿执行。玩家触发四腿的 12 次抬、迈、落，再驶入信标；结束卡回顾所选假设、预演世界及实际行动。

取消预测、改变选择或走法会失效旧结果。检查点恢复清空旧认证；新局重新显示目标与操作教学。候选世界通过只支持这组假设下的判断，实际月面仿真继续检验它。

## 感知展示与真实计算

二维轮廓是标明用途的教学显示，临时移除纹理、光照与阴影线索，让玩家体验尚未补足局部未知空间的状态。它使用完整原网格，既不删除未见三角面，也不更改原 RGB-D、配准、模型或物理信息。执行恢复原材质。这里的基线是未启用生成式空间想象模块的机器人。

原 GLB、生成输入、任务身份与冻结核对保持。试玩载入已保存的真实返回，当前相机画面没有提交新的生成请求。研究结果、报告 V3 与当前游玩结果分别记录。

## 实现与验收

- [mission-story.js](../site/mission-story.js)管理开场、操作教学、认知对比与核心进度。
- [mission-scene.js](../site/mission-scene.js)绘制完整实体、二维观测示意与候选三维局部空间。
- [mission.js](../site/mission.js)把用户输入、有效预测、驾驶、轮腿执行和复盘连起来；原 worker、物理控制与规划保持。
- [浏览器验收脚本](../tools/beforestep_mission/check_spatial_game_browser.py)通过实际按键与按钮验证整条链路，不注入机器人姿态。
- [运行记录与实景图](../evidence/spatial-imagination-20261118/README.md)保存各阶段实际状态、候选任务号与完成结果。

在已安装 Playwright / Chromium 的环境中，对正在运行的站点执行：

```sh
python tools/beforestep_mission/check_spatial_game_browser.py \
  --base-url http://127.0.0.1:8000 \
  --output /tmp/beforestep-spatial-check
```

可用 `--chromium` 指定已安装的浏览器。脚本检查开场输入锁、真实驾驶/刹车、二维观测、Q 打开的三维局部假设、取消与有效预测、整局 12 个玩家动作、抵达复盘、检查点、换组与模式切换。生成模型及原研究复现另见[任务实现](mission.md)、[资产来源](../site/media/mission/manifest.json)和[原 R1 结果](reviews/RESULT_BEFORESTEP_R1.md)。
