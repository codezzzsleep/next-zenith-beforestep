# 先见一步：从看模型到空间判断

高石的背面会占据通道，但旋转一个悬空模型不容易解释它怎样影响下一步。月面任务现在把原照片、真实 Lux3D 候选和配准后的局部占地接在同一个脑内窗口中，并同时显示两种规划走法。

- 亮色实边是原观测中的可见占地；半透明琥珀色与虚边是所选准入候选新增的占地。斜纹仍表示原观测未知区域。
- 灰色虚线只使用可见信息规划，金色实线加入所选候选占地。两条路线来自同一规划器、同一起点，选择候选会更新占地与路线。
- 金线完整通过当前候选世界的 MuJoCo 预演后才变绿。投影规划余量、候选世界中的接触和实际执行结果分别呈现。
- “符合可见面（核对）→ 候选世界通过（预演）→ 实际出发（执行）”依次显示选择、世界数量、完成/接触和路线认证。取消、换组或改变起点/姿态不会获得有效出发认证。
- 绕行提示说明正在使用哪种依据；门槛处接回“高石已绕过，前方低门槛已看清”。完成卡读取本局实际转看的目标、执行时的候选任务号、完成预演的不同世界及玩家动作数。

占地直接读取 `mission.json.gz` 中原 R1 的 `observation_state` 与准入候选 `footprint`，与规划器使用的数据一致。地图没有读取当前真实世界的隐藏背面；当前相机观测和既有生成输入分别显示。原 GLB 仍由官方 Aholo Viewer 展示，游玩不创建新的 Lux3D 任务。

在本轮桌面核查的观察点，灰线也在默认两个候选世界中完整通过；添加较宽准入候选后，四个世界仍通过。界面因此没有把灰线固定写成必碰。生成占地改变了规划走法，但这次游玩不能证明只按可见面一定失败，也不能代替冻结 R1 的独立策略对照。

原控制、碰撞、准入门槛、M20 外观资产和 V3 主报告保持。新增显示和局内复盘属于可玩任务；R1/R2/R3 的原输入、模型、轨迹、失败及版本比较仍保留。
