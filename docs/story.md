# 先见一步：先形成空间假设，再决定怎么走

当前完整参赛故事见[从照片到局部空间](submission-story-20261117.md)，事实与公开来源见[核查记录](submission-story-sources-20261117.md)。主报告为 V5 Beta，主宣传片为作者 B站视频，最新试玩与原片见[当前交付](current-status.md)。

机器人能测到可见表面，遮挡却会留下未知占地。只信可见面可能低估障碍，把未知全当危险又可能停在可通行的路前。BeforeStep 让 Lux3D 根据普通照片提出完整形状，再结合实际观测核对、配准，构建用于导航的局部空间假设。

模型实际决定占据与候选路线。MuJoCo 让同一机器人在每个假设世界里完整试走，再用独立场景中的实际执行检验判断。我们把这个空间想象模块比喻为机器人的前额叶。

R1 同一窄道中，乐观一眼碰撞、保守五眼停车，Lux3D 与十二世界预演支持一眼、112.84 秒仿真时间到达。扩展场景也保留失败：生成的背面可能偏短，完全未形成观测目标的障碍可能被遗漏；收紧规则减少本批碰撞，也增加停车。结果支持有条件的局部通行价值，不支持任意未知环境的泛化保证。

轮腿与空间想象解决相邻的执行问题。对已测清楚的低门槛，腿靠可见几何跨越；高石未知背面的假设帮助绕行判断。已有对照中也有不使用生成仍到达的路线，不能用四车示意宣称所有场景都缺一不可。[轮腿最终研究结果](reviews/RESULT_WHEELLEG_CROSSING_FINAL.md)。

这条链路已成为可操作的月面任务：自然遮挡下留下初判，自选手控、空间想象、补看或停车；在原模型构成的候选世界试路，然后自己驾驶并触发四腿动作。M20 是显示外观，原 Go2W 物理与控制冻结。试玩、研究与原片分别记录身份。
