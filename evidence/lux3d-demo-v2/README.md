2分37秒、1080p30、中文配音与烧录字幕，加入电子氛围背景音乐与17处短过渡。音乐在口播时压低；照片归位后展开模型，模型衔接到预演，单世界缩入多世界，六个资产版本横向滑动。

主线：照片 → Lux3D 三维模型 → 核对 → 路线预演 → 机器人行动。作品已实际使用Lux3D四百多次，生成模型用于判断。观众可以查看原照片、旋转模型并回看判断和行动。主流程时钟、同任务原照片/原GLB及全部实验结论保持；片尾两句突出实际使用和可体验内容。所有运动为已注明的MuJoCo原运行回放，原始模型用官方Aholo Viewer录屏。原片保留在 [lux3d-demo](../lux3d-demo/README.md)。
