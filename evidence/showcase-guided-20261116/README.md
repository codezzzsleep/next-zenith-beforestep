完整录像来自最终代码的连续 Chromium WebGL / MuJoCo 浏览器运行。实际经历观察点、官方 Aholo Viewer 原 GLB 转面、默认两模型碰撞世界预演、辅助路线及键盘接管、当前可见门槛预演、玩家按键触发四腿12个主要动作、回轮行与抵达完成卡。没有注入机器人位置或用预录片段代替脑内预演。

worker 从新停稳位置执行相同默认两世界链也抵达；候选修订/取消/姿态认证、不能跳过展示、手控没有虚构通过结果、桌手机20项交互检查通过。静态截图来自另外的手控检查，完整录像采用经过真实预演的辅助路线。必要的支撑与重心准备由原控制器辅助。

模型是项目原 R1 的真实 Lux3D 返回，当前相机没有提交新生成请求。“右顶叶”是角色的拟人台词。新的游玩成绩与原研究实验分别记录，原输入、模型、准入、物理世界、规划与轮腿控制器保持。

当前使用软件 WebGL；手机检查使用 Chromium 的实际触屏事件模拟，未在真实手机上做性能测试。模型假设通过预演仍不保证未知背面正确，实际机器人结果由独立真实场景的碰撞计算产生。原 v1 完整录像另保留在 `evidence/game-experience-20261116/`，不能混称为本轮新增观察点的录制。

本轮录像为 H.264、1280 × 800、25 fps，时长 332.96 秒、8324 帧，完整解码通过。
