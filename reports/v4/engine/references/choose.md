# 表达形式选择规则

目录：封面；15 类信息关系；流程阈值；矩阵；时间；数据图表；装饰与真实素材。

## 封面：7 种构图，不是 7 份固定文案

所有封面只要求 `title`。副标题、导语、赛事名、团队、日期、成果数字都按材料选填。不要自动加“我们如何验证”或三个数据卡。

| 构图 | 素材条件与阅读任务 | 备选 | 不应选择的情况 |
| --- | --- | --- | --- |
| horizon 地平线 | 横向场景；需要展示空间、环境或语境 | poster / split | 没有场景特征，只因领域是文旅而套山水 |
| poster 整幅海报 | 一张有力量的主视觉或清楚标作装饰的主题意象；开篇文字短 | horizon / type | 大图中细节需要逐字读；开篇说明很长 |
| type 字体主导 | 概念、研究、机构申报；无可靠图片也可成立 | frame / split | 不应把它当成缺图时的失败占位 |
| split 左右分栏 | 纵向照片、物体、产品或装置；与说明并置 | horizon / type | 需要完整横向全景；长标题在半栏无法阅读 |
| numbers 数据主导 | 1–3 个已核对、足以承担开篇主张的量 | type / horizon | 无可靠关键量、只有未来目标、为凑数编指标 |
| frame 框景题签 | 档案、机构、出版与文化语境；画面较克制 | type / horizon | 把文化等同于仿古，或把现代项目强行做旧 |
| mosaic 素材拼图 | 2–4 张互补的真实产出，各自提供不同信息 | split / horizon | 复制同一张图凑格；只有装饰图却宣称多项成果 |

有真实主图时优先保留其特征。没有可靠主图时可选择 type，不必先造一张“产品图”。`visual.art` 可明确提供程序意象，但不能暗示它是真实产出。

## 信息关系是组合，不是固定“数据种类”

分开辨认：字段类型（数值、类别、日期、文字、位置、角色、节点/边）与阅读关系（比较、变化、归属、顺序等）。一段材料可以同时有多种关系；选读者此刻最需要的一个作主图，精确值与解释保留在图注或表里。

15 类关系及默认入口见 SKILL.md。下列阈值是本系统的版式默认值，可被标签长度、素材比例、读者任务覆盖。不要把默认阈值写成研究结论。

## 流程：先看关系，再数步骤

| 材料形态 | 首选 | 何时升级/拆分 |
| --- | --- | --- |
| 1 个动作 | 文段或动作卡 | 不为单动作画箭头 |
| 2–3 个简单线性动作 | 编号列表，或需要空间说明时用 process | 单步含多段说明时保持正文 |
| 4–7 个线性步骤 | process；2–4 步可横排，5–7 步默认纵排 | 需要显示输入输出与校验点时用 diagram.flow |
| >7 步 | 3–5 个主阶段 + 对应子流程 | 每个原步骤仍有去向，不合并掉例外 |
| 任意数量但存在分支/校验 | diagram.flow，判断节点用 diamond | 画出条件；不能只用“下一步”串平 |
| 两个以上角色有交接 | diagram.swimlane | 只有职责清单时用表，不画假交接 |
| 明确反馈闭环 | 单独画 cycle 或拆开主干与回路 | cycle 必须声明全部闭环边；不要给线性流程补闭环 |
| 系统多节点连接 | architecture 总览 + 子图 | >12 节点优先分图；渲染器单图硬上限 16 节点 |

单层横向最多 4 节点。不在 A4 上排一条 9 格的小字长链。分支图的每条边必须来自材料；箭头方向、条件和输入输出不可凭视觉直觉补充。跨页续表/列表可以自动生成；拓扑图需要先设计拆分边界。

## 对比矩阵：什么时候用

- 2–6 个对象，在 3–8 个**共同维度**上比较，尤其是“功能、使用条件、限制、责任”等定性或混合字段：用 matrix。
- 只有一个同口径数值：条形、柱形或点图更直接；只有两个方案、两个条件时，一对卡片也可以。
- 多维均为同尺度数值：可用 heatmap，同时保留数值和色阶说明。单位不同、尺度不同则分列显示或分图，不直接套同一色阶。
- 未给权重与评分方法：不得擅自构造 1–5 分、总分、星级、雷达面积或冠军标记。
- 缺失资料写“未提供/待核对”，不写“不支持”。不把自己的方案整行涂成“通过”而省略比较口径。
- >6 对象、>8 维度：按阅读问题拆表，或将全量明细放附录；所有字段仍有出处。

## Timeline、roadmap 和 Gantt 的边界

| 重点 | 首选 | 数据要求 |
| --- | --- | --- |
| 1–2 个事件的日期 | 键值或短段落 | 已给定的日期 |
| 3–5 个短里程碑 | timeline-horizontal | 日期或明确的相对时间 |
| 6–10 个事件，或说明长 | timeline 纵向 | 时间顺序可核对；允许失败/转折节点 |
| >10 个事件 | 按时期分组、连续多页 | 不省略原事件；主线可加概览 |
| 阶段目标，尚未确定时间 | roadmap | 阶段及任务；不补造具体日期 |
| 持续时间、并行任务、交付排期 | gantt | 每个任务有真实 start / end；里程碑单点 |
| 谁先做什么但没有时间 | process | 这是动作顺序，不需要日期 |

Timeline 的节点默认等距，仅表示先后；图注说明它不表示间隔长短。需要按时间尺度读长度时改用 Gantt。计划与已发生事件用明确文字区分；颜色不能替代“计划/完成/失败”等状态文字。

## 18 种数据图表：选择与替代

| kind | 选择条件 | 备选/限制 |
| --- | --- | --- |
| bar | 2–6 个短标签、同口径数值 | 数值长度从零起；长标签改 hbar |
| hbar | >6 类、长标签、排序任务 | 不自动排序，先确定排序含义；过多分类改表 |
| grouped | 2–4 系列在同分类上比较 | 系列多时分面；无共同单位时分图 |
| stacked | 相同整体中各部分的绝对量 | 不能堆叠互不相干的指标 |
| stacked100 | 多个整体的组成比例 | 保留分母；不能隐去样本总量差异 |
| line | 连续时间/连续序列的趋势 | 分类没有连续顺序就不要连线；当前脚本不接收缺测值 |
| area | 连续、非负总量趋势，面积有意义 | 多组重叠会遮挡；优先少系列或单系列 |
| dot | 同量纲类别比较，想降低墨量 | 需要精确查值时仍可用表 |
| slope | 多个对象在两个同口径时点的变化 | 两时点以外用 line；只有一对数可用 delta |
| donut | 一个整体、2–5 个较少部分 | 5 以上优先横条或堆叠；程序最多接受 6 部分 |
| scatter | 成对 x/y 数值，观察关系 | 气泡第三量用面积；无配对样本不可画 |
| histogram | 原始连续样本分布 | 注明分箱规则；不能由均值与最大值反推样本 |
| box | 多组原始样本，需要看中位数/离散/离群 | 明确 Q1/Q3 与 1.5 IQR；无样本时用已有统计表 |
| heatmap | 行×列数值矩阵、同尺度色阶 | 不同单位不要统一着色；纯定性用 matrix |
| gantt | 任务起止、工期、并行 | 不表示未声明的任务依赖；依赖关系另画流程 |
| waterfall | 可加总的增减项导致总量变化 | 注明起始值语义，输入首项可为起始量；非加总用 bar |
| funnel | 连续转化阶段，后阶段是前阶段子集 | 仅数值递减并不能证明子集关系，先核对材料 |
| range | 中心值与给定上下界 | 必须声明区间口径；不自动称为置信区间 |

图表优先显示真实值、单位、时间/样本口径、出处。图表是否“好看”不能改变原始数值。禁止 3D 柱、双纵轴拼巧合、伪造误差条、从定性描述生成量化图。精确审查时保留表格，不执行“所有数据先图后表”的强制规则。

## 插画与真实素材

`ridges / contours / network / waves / orbits / blocks / halftone` 是 7 种可复现的程序 SVG 意象。它们不承载项目事实。不要用 network 代替真实架构、用 contours 代替真实地图、用 ridges 代替地质数据。

可使用真实图片、用户授权的生成图或程序意象作封面装饰；数据图与拓扑图必须由精确数据/节点边生成。保留真实截图中的坐标、图例、单位和警告；证据图默认 contain，不能 cover 裁去边缘信息。
