# 渲染与质量检查

## 环境

Python 3.10+，依赖见 requirements.txt；使用 WeasyPrint 排版，PyMuPDF 提取与渲染，NumPy 生成程序插画及统计计算，Pillow 生成联系表。系统需要 Pango 与可用中文字体。先运行 `scripts/doctor.py`，不要在缺字体时继续交付。

优先使用 Noto Serif CJK SC / Noto Sans CJK SC，依次回退到思源、苹方、微软雅黑、宋体等。无等宽中文字体时，中文标签仍使用系统回退字体。图表 SVG 保留矢量与可选中文文本。

## 已处理的 PDF 排版限制

- `scripts/css.py` 在渲染前解析当前风格的 CSS token 与长度运算；不要依赖后端静默忽略 `calc()` 后产生的样式。
- 原始 CSS 中的 `inset` 不用于关键尺寸，关键封面明确写 top/left/width/height。
- 不用阴影承担信息，不用滤镜、动画、3D、交互图例或隐藏正文。
- 主体内容按实际高度测量，由引擎显式续页，不让后端暗中产生未审查的碎页。
- 外部图片必须先作为本地文件核对；输出 HTML 内嵌素材，无需联网。

## 自动检查证明什么

| 检查 | 能证明 | 不能证明 |
| --- | --- | --- |
| 源单元覆盖 | 每个必保留单元都有去向；逐字块片段组合完整 | OCR 正确、台账没有漏项 |
| PDF 文本核对 | 每个原文片段可在最终 PDF 文本中检出 | 图像中文字正确、改写语义无损 |
| 事实引用 | 已声明并引用的事实 display 出现在 PDF | 所有数字都已纳入台账、数据口径本身正确 |
| 可见文字核对 | 非 SVG 的 HTML 文字确实进入排版树，防止固定容器静默漏排 | SVG 内部文字重叠、OCR 或图像中的文字 |
| 高度与边界 | 常规页/整页主要内容不越过可用区 | 所有视觉上的遮挡、色彩或 SVG 内部标签碰撞 |
| 封面碰撞 | 标题说明区不压住元数据/数字带 | 所有图片中的细节和底色对比都适合 |
| 联系表 | 可概览全册节奏、孤页、图像缺失 | 小字号是否清楚、细线是否断裂 |

不要写“自动检查全部通过，因此内容无损”。读原材料、看台账、逐页看成稿是三个不同步骤。

## 容量处理

可自动拆：source 原文单元、长普通段落、list、cards、stack、table、matrix、timeline。续表重复列头；续页有标题“续”。表格单行、复杂卡、row、chart、diagram 和整页组件不能任意截断，需要主动改变组合。

对于正文：先续页。对于图表：先改通栏或分组。对于封面：先换构图。对于过长单元：在句界附近拆分，片段仍完整拼回原文。对正文不使用省略号、字号缩放或 max-height 截断。

孤行、短尾页、重复说明等仍需人工调整。留白不是错误；能解释阅读任务的留白可以保留。为满足页底填充率而添加内容是不允许的。

## 交付前逐页看

1. 封面标题、副标题、长项目名是否可读；元数据和数字带是否相撞。
2. 页头有无无意义的数字序号；同一层级是否一致。
3. 正文、表格、图注、页脚有无裁切、压线、缺字、异常断行。
4. 图表横纵轴、系列、单位、图例、样本、区间口径和出处是否完整；不要只看缩略图。
5. 真实图片是否保留边缘标注、图例和警告；照片裁切不影响证据含义。
6. 流程箭头是否表达材料真实关系；判断分支是否都展示；跨角色交接是否清楚。
7. 时间线的计划/完成状态是否写明；等距节点没有暗示真实间隔。
8. 原材料中的条件、反例、未完成事项、脚注和链接是否有去向。
9. 目录是否指向最终物理页；续页/续表保持顺序、表头与内容。
10. 最新 PDF 再渲染后查看，不能用上次的截图证明新版没有问题。
